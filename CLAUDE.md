# EdgeX Learning – project notes for Claude Code

Redesign of https://edgex-learning.com (Mumbai coaching institute: CA, ACCA, CFA, 11th-12th Commerce) from WordPress/Elementor to a modern animated React site. Owner: Alphabet Beta Solution (website@alphabetasolution.com). WordPress stays only as a hidden CMS for blog content.

## Stack
- Next.js 16 (App Router, **static export**, `output: 'export'`, `trailingSlash: true`) + React + TypeScript
- Tailwind CSS v4 (config lives in `app/globals.css` under `@theme`, no tailwind.config)
- Framer Motion for all animation, lucide-react icons
- Fonts via npm (`@fontsource-variable/fraunces` display, `@fontsource-variable/plus-jakarta-sans` body). No Google Fonts network call.

## Commands
```bash
npm install
npm run dev      # localhost:3000
npm run sync     # re-pull blog posts + featured images from WP REST API -> data/posts.json, public/blog/
npm run build    # static site -> ./out  (upload contents of out/ to web root)
```
No backend. Output is plain HTML/CSS/JS.

## Structure
- `lib/site.ts` – **single source of truth**: SITE flags, CENTRES, NAV, FACULTY, COURSES (4), INCLUDES, TESTIMONIALS, `WA_LINK()`. Edit content here first.
- `data/posts.json` – generated by `scripts/fetch-posts.mjs` (11 posts). Don't hand-edit; run `npm run sync`.
- `app/page.tsx` – home = Hero, Marquee, Pathways, Approach, Faculty, Testimonials, BlogPreview, CtaBand
- `app/{about,blog,contact,11th-12th-commerce,ca,acca,cfa}/page.tsx` – course pages are 3-line wrappers around `components/CoursePage.tsx` driven by `COURSES`
- `app/[slug]/page.tsx` – blog posts at **root-level URLs** (same as WordPress, preserves SEO). `dynamicParams = false`; Next 16 `params` is a Promise.
- `components/` – Navbar, Footer, PageHero, CtaBand, ContactForm, WhatsAppFab, Reveal (Reveal, SplitWords, Counter), `home/*` sections
- `public/img/` – all images downloaded from the old site (logo, faculty, hero cut-out, course diagrams, testimonial avatars)

## Design system
- Colors (globals.css `@theme`): navy `#0d1840`, navy-2, ink `#0a1030`, gold `#d4a62a`, gold-soft, plum `#4b2e6f`, ivory `#fbf8f1` (page bg), sand `#f2ecdd`. Taken from the logo (navy + gold + purple tagline).
- `.gold-text` = animated gold gradient text. Gradient must stay mid-tone (no near-white stops) or it vanishes on ivory.
- Logo (`/img/logo.png`) has dark navy text on transparent → **only place it on light backgrounds** (navbar pill, footer ivory chip).
- Pattern: dark navy hero/CTA sections with `.grain` + blurred gold/plum blobs, ivory/sand content sections, rounded-[2rem] cards.
- Animation conventions: `Reveal` for scroll fade-up, `SplitWords` for headline word reveal (`gold={[wordIndexes]}`), `Counter` for count-up. `prefers-reduced-motion` handled in CSS.
- Blog article styling = `.prose-edgex` in globals.css (WP HTML is injected; `wp-block-*` classes stripped in sync script, internal links rewritten to relative).

## Decisions made
- Next.js over plain React for SEO ("CA classes Mumbai"). Same URLs as WP: `/ca/`, `/acca/`, `/cfa/`, `/11th-12th-commerce/`, `/about/`, `/blog/`, `/contact/`, `/<post-slug>/`.
- Home shows **4** pathways (old site showed 3; CFA added since it has its own page).
- Contact form has no backend: on submit it opens WhatsApp (`wa.me/919820088974`) with details pre-filled. Swap `onSubmit` in `components/ContactForm.tsx` for a fetch() if email/Sheet storage is wanted.
- Stats shown on home/about (40+ years, 8 faculty, 2 centres, 4 programmes) come from facts on the old About page.

## Deploy
Upload `out/` contents to web root (Hostinger / EC2 nginx / any static host). nginx: `try_files $uri $uri/ /404.html;`. Keep WordPress on a hidden subdomain only if using `npm run sync` (set `WP_URL` env var to that origin).

## Gotchas
- Static export: no API routes, no server actions, `images: { unoptimized: true }`.
- Don't import `window`-dependent code in server components; animated components are `'use client'`.
- Mobile overflow bug previously came from grid children without `min-w-0` (faculty section). Keep `min-w-0` on grid children containing carousels/flex rows.
- Verified visually with Playwright + system Chrome at 1366px and 390px; no console errors, no horizontal overflow.
