# EdgeX Learning – Next.js static site

Stack: Next.js (static export) · React · Tailwind CSS v4 · Framer Motion

## Run
```bash
npm install
npm run dev          # http://localhost:3000
npm run sync         # re-pull blog posts + images from WordPress REST API
npm run build        # outputs static site to ./out
```

## Deploy
Upload the contents of `out/` to the web root (Hostinger / EC2 nginx / any static host).
nginx example: `try_files $uri $uri/ /404.html;`

## Edit content
- `lib/site.ts`  – courses, faculty, centres, phone/email, testimonials, feature flags
- `data/posts.json` – blog (auto-generated by `npm run sync`; keep WordPress as hidden CMS)
- `public/img/` – images
